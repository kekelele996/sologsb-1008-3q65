# 公共标识多语言校对台

用于公共空间标识译文录入、术语校验、版面风险预览和紧急修订的本地优先工作台。示例包含轨道交通、商场、公园和医院标识。

## 两边各管各的

现场安装班组和语言服务中心共用同一块牌子，但数据按归属拆成两份本地存储，通过 `signId` 对齐：

- **现场那份**（`sologsb-1008-onsite-v1`）只存实测尺寸与实物状态：牌面尺寸、可印区域、最小可读字号（均为现场实测 mm）、安装位置、实物状态。服务中心只读，不改写这些数字。
- **服务中心那份**（`sologsb-1008-service-v1`）只存译文与术语：原文、译文、目标语言、绑定术语、审校状态、意见、版本快照、紧急修订和下发状态。

两边定的尺寸与译法互相牵制：服务中心下发前，用现场实测的可印区域与最小可读字号校核译文能否排下。排不下的在标识清单和服务中心顶部标出**退回重核**（写明需几行/可印几行），不自动缩小字号，也不改现场量到的数字；现场班组可在「现场」视图改写实测尺寸，改写后重新校核。

## 功能

- 服务中心录入中文原文、目标语言、适用场景和法规/规范提示，绑定固定术语并实时校验必选术语。
- 按现场实测可印区域（mm）校核译文：排不下即**退回重核**，可印才允许下发；下发失败可在服务中心这边重试，现场那份照常查看。
- 实时预览 320、480、720、960 像素宽度和 28—88 像素字号下的换行、截断和溢出风险（预览为模拟，是否可印以现场实测校核为准）。
- 统计预计行数、字符数和未命中的必选术语，并给出高风险、需留意、版面安全三级判断。
- 支持草稿、待确认、需修改、已确认四种审校状态；紧急修订把已确认标识重置为待审校，强制重新确认。
- 添加审校意见、回复并标记解决状态。
- 保存最多 12 个版本快照，按词/字符比较旧版与当前译文，绿色表示新增、红色表示删除。
- 生成只读预览链接；链接读取当前浏览器保存的本地版本，不提供服务端数据。
- 多步撤销/重做、本地自动保存、断网继续编辑。
- 键盘操作：`J`/`K` 切换标识，`[`/`]` 切换预览宽度，`-`/`=` 调整字号。

## 本机旧数据迁移

首次打开时，若检测到旧版单份草稿（`sologsb-1008-project-v1`），按归属迁移到两边再启用：译文、术语、审校结论归入服务中心；安装位置、实物状态归入现场。旧稿没有实测尺寸，用按场景的默认值补齐（mm），由现场班组实测改写，系统不替现场改数字。迁移完成后删除旧稿。

## 技术栈

- Qwik 1 + Qwik City + TypeScript
- DaisyUI 5 + Tailwind CSS 4
- Qwik City 静态适配器
- 浏览器 `localStorage`（现场 / 服务中心两份）
- nginx 静态部署

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
```

生产构建输出到 `dist/`，由 Qwik City static adapter 生成可静态部署文件，用 nginx 托管（见 `Dockerfile`）。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口表映射为 `10008`。

```bash
docker build -t sologsb-1008 .
docker run --rm -p 10008:80 sologsb-1008
```

访问 `http://localhost:10008`。

## 数据说明

现场与服务中心数据分别保存在当前浏览器 `localStorage`，按标识 `signId` 对齐。只读预览链接仅对保存过同一浏览器本地数据的设备有效，不回传或公开业务数据。下发为本地模拟（无真实服务端），失败可重试。
