# 公共标识多语言校对台

用于公共空间标识译文录入、术语校验、版面风险预览和紧急修订的本地优先工作台。示例包含轨道交通、商场、公园和医院标识。

## 两边各管各的

同一块牌子的数据按归属拆成**两份独立本地稿**，各有独立的 localStorage 键，互不覆盖：

| | 现场那份（安装班组） | 服务中心那份（语言服务中心） |
| --- | --- | --- |
| 内容 | 牌面实测尺寸、可印区域、最小可读字号、安装位置、实物状态 | 中文原文、目标语言、译文、固定术语、审校状态/意见、版本快照 |
| 存储键 | `sologsb-1008-field-v2` | `sologsb-1008-center-v2` |
| 对方数据 | 译文只读（仅最近成功下发的一包） | 实测尺寸只读 |

切换牌子、改译法都不会冲掉现场量的数字；现场改尺寸也不会带走译文和审校结论。

## 版面牵制与退回重核

- 排不排得下，只用现场实测的**可印区域宽高**与**最小可读字号**判定（保守换行估算，固定行距）。
- 排不下时现场点「排不下 · 退回重核」，标记**具体哪块牌子（编号）**和排不下的行数原因；该牌子在服务中心同步变为「需修改」。
- **不会自动缩小字号，也不允许任何一方修改实测数字**。服务中心精简译文后重新下发，现场核对到「排得下」才能标记复核通过；仍排不下时通过按钮保持禁用。
- 现场尚未量齐尺寸时，服务中心侧只显示「待实测」，不做臆测。

## 下发与失败重试

- 服务中心侧「下发到现场」把译文包（译文、语言、术语、时间）写进现场那份；单块或全部待发都可下发。
- 每次尝试写入下发日志，累计次数。**失败后只在服务中心留失败记录**，现场那份完全不动、照旧查看上一版内容；按「重试下发」从本侧重发。
- 顶部「模拟下发失败」开关与浏览器离线状态都会触发失败路径，便于演练。

## 审校功能

- 录入中文原文、目标语言、适用场景和法规/规范提示。
- 为每条译文绑定固定术语；必选术语与译文不一致时高亮告警，可逐条确认或删除。
- 草稿、待确认、需修改、已确认四种审校状态；审校意见可回复、标记解决。
- 保存最多 12 个版本快照，旧版与当前译文按词/字符比较，绿色新增、红色删除。
- 紧急修订模式把已确认标识锁回待审校，强制重新确认。
- 多步撤销/重做（仅服务中心那份）、本地自动保存、断网继续编辑。
- 只读预览链接（`?preview=牌子id`）同时读取两份：译文取服务中心、版面尺寸取现场；不提供服务端数据。
- 键盘：`J`/`K` 切换当前那份里的标识，服务中心下 `Ctrl/⌘ Z` 撤销。

## 旧数据迁移

首次打开新版本时，若检测到旧合并稿 `sologsb-1008-project-v1`：

- 译文、术语、审校意见、版本、状态 → 迁入服务中心那份；
- 旧项目地点作为「待核对安装位置」线索带到现场那份；尺寸旧稿没有，留空待实测，不臆造数字；
- 迁移完成后删除旧键，新的两份随后才启用；页面顶部会给出迁移提示。

## 技术栈

- Qwik 1 + Qwik City + TypeScript
- DaisyUI 5 + Tailwind CSS 4
- Qwik City 静态适配器
- 浏览器 `localStorage`（两个独立键）
- nginx 静态部署

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`。Node 20 环境下通过 npm override 将 undici 固定在 7.x（undici 8 需要更高版本 Node）。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口表映射为 `10008`。

```bash
docker build -t sologsb-1008 .
docker run --rm -p 10008:80 sologsb-1008
```

访问 `http://localhost:10008`。

## 数据说明

两份数据都保存在当前浏览器 `localStorage`，不回传业务数据。只读预览链接仅对保存过同一浏览器本地数据的设备有效。
